# CodeAlpha-HotelReservationSystem
Hotel Reservation System

A Java backend project developed using Spring Boot and MySQL for the CodeAlpha Java Programming Internship.

Technologies Used

- Java
- Spring Boot
- MySQL
- Spring Data JPA
- Postman

Features

- Add, view, update, and manage hotel rooms
- Create and view bookings
- Validate booking dates
- Prevent overlapping bookings
- Cancel reservations
- Simulate payments
- Store data in MySQL
